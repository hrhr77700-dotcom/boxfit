# BoxFit

물건 하나의 크기와 포장 여유로 알맞은 택배 박스를 추천하는 한국어 정적 웹사이트입니다.

## 실행 방법

**`index.html` 하나만 다운로드하고 더블클릭해서 브라우저에서 여세요.** CSS, JavaScript, 박스 데이터가 모두 HTML에 포함되어 있어 다른 파일, 설치, 빌드, 서버가 필요하지 않습니다. 모바일 화면도 지원하며 로그인, 결제, 외부 API 및 외부 폰트를 사용하지 않습니다.

1. 가로·세로·높이를 cm 단위로 입력합니다. 소수를 허용합니다.
2. 포장 여유를 선택합니다. 기본값은 2 cm입니다.
3. **맞는 박스 찾기**를 누르면 내부 부피가 작은 순서로 최대 3개를 표시합니다.
4. **예시 입력**은 20 × 15 × 10 cm, 여유 2 cm로 즉시 추천합니다. **초기화**는 입력과 결과를 처음으로 돌립니다.

여유는 각 치수에 총합으로 한 번 더합니다. 20 × 15 × 10 cm에 여유 2 cm를 선택하면 필요한 내부 크기는 22 × 17 × 12 cm입니다. 여섯 가지 직각 회전을 검사합니다. 대각선 배치, 물건 변형 및 여러 물건의 동시 포장은 계산하지 않습니다.

결과에는 박스 내부 가로 × 세로 × 높이, 부피(cm³), 원래 물건의 배치 방향 및 축 대응을 표시합니다. 맞는 박스가 없으면 필요한 최소 내부 크기를 안내합니다.

**추천 박스는 기능 확인용 예시 규격입니다. 실제 판매 상품이나 우체국 규격이 아닙니다.** 가격과 구매 링크는 제공하지 않습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 스타일·박스 데이터·추천 로직을 모두 포함하는 단독 실행 파일 |
| `styles.css` | 크림색·주황색 디자인 및 반응형 배치 |
| `boxes.js` | 기능 확인용 박스 내부 규격 13개 (cm) |
| `recommend.js` | 입력 검증, 회전 판정, 부피 정렬 |
| `app.js` | 입력·추천·초기화와 결과 표시 |
| `tests/recommend.test.cjs` | 추천 로직 자동 검증 |
| `tests/standalone.test.cjs` | 단일 HTML의 외부 의존성 및 원본 일치 검증 |

배포용 `index.html`은 외부 파일을 읽지 않습니다. 박스 규격은 HTML 내부의 `BOXFIT_BOXES` 목록(`[이름, 가로, 세로, 높이]`)에서 수정할 수 있습니다. 분리된 CSS·JS 파일은 개발용 원본으로 남겨두었습니다. 원본 변경 시 HTML에 포함된 내용도 함께 갱신해야 합니다. fetch와 JavaScript 모듈을 사용하지 않습니다.

## 검증 방법

사이트 사용에는 Node.js가 필요하지 않습니다. 자동 테스트는 Node.js 18 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
node --test tests/*.test.cjs
```

브라우저에서 확인할 예:

- 회전: 10 × 20 × 15, 여유 0 → 첫 추천 컴팩트(20 × 15 × 10), 물건 세로·높이·가로 순으로 배치.
- 딱 맞음: 예시 입력 → 필요 크기 22 × 17 × 12, 첫 추천 데일리.
- 너무 큼: 100 × 90 × 80, 여유 2 → 추천 없음, 필요 크기 102 × 92 × 82 안내.
- 잘못된 입력: 빈 값, 0, 음수, 문자 → 한국어 오류 안내.
- 소수: 19.5 × 14.5 × 9.5, 여유 2 → 소수 크기를 유지해 계산.

외부 공개 배포는 수행하지 않았습니다.

### 단일 HTML 검증 결과

HTML 안에 모든 스타일·데이터·스크립트가 포함되어 있고 개발용 원본과 일치하는지 자동 검사합니다. Chromium에 HTML 전체를 직접 로드하여 서버·외부 요청 없이 PC·모바일 추천, 회전, 딱 맞음, 크기 초과, 오류 안내, 소수, 예시 입력과 초기화를 확인했습니다. JavaScript 오류와 가로 넘침은 없었습니다. 클라우드 브라우저 정책이 `file://` 접근을 차단하여 실제 더블클릭 방식 자체는 직접 검증하지 못했습니다.

사용자가 다운로드한 단일 HTML을 PC에서 직접 열어 박스 추천이 정상 동작함을 확인했습니다. 저장소의 `index.html`은 해당 다운로드 파일 및 ZIP 내부 HTML과 바이트 단위로 동일함을 확인했습니다.
